# Compatibility — v1.0

| Environment | Evidence |
| --- | --- |
| Anbernic RG40XX H / VBA Next | Primary owner-accepted setup: exact RC1 checklist reported passed for title/music, normal battles, abilities, copied-save progress, native Save and cold Continue. Exact firmware/core version and numerical latency were not independently measured. |
| Desktop mGBA / VBA Next | Scoped title, menu, generated-save and gameplay evidence in the recorded test evidence. Some facility checks use the frozen gameplay predecessor with source continuity to title-only RC1. This does not certify every optional path or every core version. |
| Other GBA emulators/devices, including physical iPhone/Delta | Unverified for this candidate unless additional evidence is recorded. General GBA support alone is not a compatibility guarantee. |
| DSi / GBARunner2 | Separate experimental candidate; excluded from the main package. Owner boot/save/reload pass, with unresolved transition graphics/audio delay. No change to the main ROM is planned. |

Keep device reports distinct from automated desktop results. Do not treat the curated emulator screenshots as handheld acceptance or a complete playthrough.

Same-edition copied battery-save use passed owner acceptance, but arbitrary prior versions, emulator save states, link interoperability and cross-edition DSi migration are not certified. Follow [installation precautions](INSTALL.md). See [known limitations](KNOWN-LIMITATIONS.md) for the remaining timing and optional-content uncertainty.
