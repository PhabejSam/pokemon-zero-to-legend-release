# Report a problem

Please [open a GitHub issue](https://github.com/PhabejSam/pokemon-zero-to-legend-release/issues/new) with:

- Game version (v1.0) and whether the patch checksum matched.
- Device, emulator/core version and relevant settings.
- Location, battle format, party species/levels and the steps that reproduce the issue.
- Expected behavior, actual behavior, and an optional spoiler-safe screenshot.
- Whether it happens after a cold launch and normal Continue.

Check [known limitations](KNOWN-LIMITATIONS.md) first. Keep a backup; do not overwrite your only working save while investigating.

**Do not attach ROMs, BIOS files, personal saves, private correspondence or personal information.** Avoid Level 100 move names or animation previews in public titles and screenshots. Report the category without revealing the surprise.
